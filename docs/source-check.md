# Source check

Every official page the tool cites was opened again on 4 November 2026 to confirm that it loads,
is on an official site and still supports the rules that cite it (check 9). The pages are listed
in `estimator/rules/rules_2026.json`; the loader refuses any source that is not an official https page.

Result: 54 pages. All load and support their rules, except one that blocks automated
visits (the ESTV calculator, which opens normally in a browser). Two texts were corrected
(sponsor duties, passport renewal) and two rules got an extra source (Swiss unemployment
insurance, minimum federal tax); see the notes.
